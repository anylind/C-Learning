# C Learning Journey

This repository collects small C exercises and projects created while learning the language and exploring low-level programming concepts. The examples are grouped by topic:

## Project map

- **Data structures** — implementations of a [singly linked list](data-structures/simple-linked-list.c), [doubly linked list](data-structures/simple-Doubly-Linked-List.c), and [dynamic vector](data-structures/simple-vector.c).
- **[File I/O](file-io/README.md)** — command-line file utilities, a hex viewer, and programs that store records or notes in files.
- **Memory** — a [memory inspector](memory/mem-inspector.c) experiment.
- **[Miscellaneous experiments](misc/)** — other standalone C programs.

The projects explore pointers, structs, dynamic memory, arrays and strings, file streams, and binary data. Most examples are independent programs; the multi-file projects have their own Makefiles where provided.
